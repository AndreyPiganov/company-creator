## Модели и цены

Цены за 1 млн входных/выходных токенов сверены с официальными карточками [GPT-6 Sol / Astra / GPT-6.1 Sol](https://developers.openai.com/api/docs/models/compare?model=gpt-6-sol), [GPT-4.1 Mini](https://developers.openai.com/api/docs/models/gpt-4.1-mini) и [GPT-4.1](https://developers.openai.com/api/docs/models/gpt-4.1). GPT-6 Luna остаётся моделью по умолчанию.

Для OpenRouter нужна заявленная поддержка [Structured Outputs](https://openrouter.ai/docs/guides/features/structured-outputs). Одного JSON mode (`response_format`) недостаточно для подтверждения поддержки JSON Schema.

Если резерв максимального ответа уже выше лимита, модель недоступна для выбора. Остальная оценка выполняется backend с учётом запроса. GPT-6 Astra не проходит при стандартном лимите $0.25. Каталог не повышает бюджет автоматически.

## Оставшаяся приёмка

До заявления о полном соответствии нужно усилить смысловые проверки RU/DE, проверку состава руководства и учёт расходов неуспешных AI-попыток. UI/HTTP-проверки и тесты адаптеров не заменяют проверку содержания. OpenRouter проверяется моками; реальный вызов требует его ключа.

## Проверки этого обновления

В Docker прошли production build, 20 backend-тестов, TypeScript и линтеры обеих частей. Chromium проверил 10 страниц при ширине 1440 и 390 px: панель, формы и по три страницы RU/DE-примеров. Проверены текст основной кнопки, поиск моделей, выбор палитры, скачивание ZIP, отсутствие горизонтального переполнения и JavaScript-ошибок. Созданы новые версии двух примеров; контрольные суммы главных страниц старых версий не изменились. Все четыре сервиса проходят healthcheck. Шесть моделей OpenAI присутствуют в каталоге подключённого аккаунта; платная генерация каждой из них в этой проверке не выполнялась.
